## 🌟 Overview

**AL-REHMAN Welding Works** is a modern, high-performance web application designed for a premier metal fabrication and welding workshop located in Shiroor, Karnataka. Built with precision and attention to detail, the platform showcases high-quality craftsmanship, completed projects, and provides a direct, friction-free WhatsApp quote request system.

---

## ✨ Features

- **Hero Experience**: Seamlessly embedded, permanently muted, looped welding video background with bold typography and quick call-to-actions.
- **Service Catalog**:
  - 🚪 **Gates & Grills**: Main gates, iron fabrication, custom sliding gates, window grills, security grills.
  - 🪜 **Railings & Staircases**: Staircase railings, balcony railings, steel handrails, metal staircases.
  - 🏗️ **Sheds & Roofing**: Metal shed structures, car parking sheds, terrace roof trusses, canopies.
  - ⚙️ **Structural Steel**: Steel frame fabrication, structural trusses, custom metal components.
  - 🛠️ **Welding & Repairs**: On-site & workshop welding repairs, broken metal joint restoration.
- **Project Portfolio**: High-resolution gallery displaying real fabricated structures and installations.
- **Interactive Quote System**:
  - Dynamic service and job size selection.
  - Pre-fills details directly into a formatted WhatsApp message (`wa.me`) for instant response without payment friction.
- **Floating WhatsApp Quick Action**: Persistent one-click chat icon for direct inquiry.
- **Responsive & Accessible**: Optimized for mobile, tablet, and desktop viewports with fluid navigation and micro-animations.
- **Permanently Muted Media**: All video assets (`welding-sparks.mp4`, `logo-reveal.mp4`) are stripped of audio tracks and locked at zero volume to ensure silent, non-intrusive playback across all devices.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your machine:
- [Node.js](https://nodejs.org/) (v20 or higher recommended)
- [npm](https://www.npmjs.com/) (v10 or higher)
- [Git](https://git-scm.com/) with [Git LFS](https://git-lfs.github.com/)

### 1. Clone the Repository

```bash
git clone https://github.com/mohhdmufeed/AL-Rehman_webs.git
cd AL-Rehman_webs
git lfs pull
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run Development Server

```bash
npm run dev
```

The application will be running locally at `http://localhost:8443/` (or your configured `$PORT`).

### 4. Build for Production

```bash
npm run build
```

This compiles optimized production-ready HTML, CSS, and JS bundles into the `dist/` directory.

### 5. Format Code

```bash
npm run format
```
